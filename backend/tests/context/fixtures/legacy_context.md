## 0-A 프로젝트 개요

- 제품명: 에어컨
- 한줄 정의: 쾌적한 실내 환경을 만드는 제품
- 리서치 질문: 어떤 불편이 있는가?
- 질문 템플릿: 질문 템플릿
- 프로젝트 유형: 리뉴얼 (기존 제품 개선)
- 분석 목표: 니즈탐색 (사용 불편 중심)
- 핵심 지표 (방향 지시자, 측정값 아님): 편의성, 만족도
- 사내 제약: 예산 제한
- 가격 포지셔닝: 프리미엄
- 시장 포지셔닝: 신규 진입자
- 수집 채널: 네이버 블로그, 개발용 샘플
- 제품 분류: 가전 > 냉방 > 에어컨
- 제품 분류 출처: 언어 모델 추정

## 0-B 분석 대상 · 초기 기준선

분석 대상 초기 기준선 — 우선 탐색하되 범위 밖 발견도 배제하지 말 것, 해석을 조정하지 말 것

- 연령대: 30대
- 성별: 여성
- 가구 유형: 1인 가구
- 생애 단계: 사회 초년기
- 분석 대상 메모: 우선 검토
- 미래 고객: 구매 관망자 (구매 전환 탐색)
