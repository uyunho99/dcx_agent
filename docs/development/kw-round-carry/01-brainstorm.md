# 키워드 화면 — 이전 라운드 승인 단어 누적 + 라운드 표시 · 기획

기준: origin/main `8c7a693`(kw-round-view 배포본)

## 문제
kw-round-view 배포 후 R3 화면은 R3 단어만 보여준다. 사용자는 R1 → R3로 넘어가면서 R1에서 거절하지 않은(승인한) 단어까지 사라졌다고 보았다. 데이터는 그대로다(세라젬 운영: R1 승인 67 · 거절 20 저장, 크롤링 전달 대상).
그 전(누적 목록)에는 R1 거절 단어까지 섞여 R1과 R3가 "똑같다"고 보였다.

## 결정 (사용자, 2026-10-02)
- "승인 누적 + 이번 라운드, 표시로 구분" 선택.
  - R3 화면 = 이전 라운드에서 승인한 단어 + 이번 라운드 단어. 이전 라운드 거절 단어는 보이지 않는다.
  - 이전 라운드 단어 칩에는 "R1" 같은 라운드 표시를 붙여 이번 라운드 새 단어와 구분한다.

## 동작
- 라운드 n 화면 목록 = `round === n`인 단어 전부 + `round < n`이고 거절되지 않은 단어.
  - 세라젬 R3 화면: R3 60 + R1 승인 67 = 127. R1 거절 20 · 미확정 R2(서버가 이미 숨김)는 없음.
  - R1 화면: R1 단어 전부(87, 지금과 같음).
  - 최종 화면(R4 확정 후): 지금처럼 전체 누적.
- 이전 라운드 단어 칩: 기존 칩 표시(수동 · 미연결 등) 자리에 `R{round}` 표시 하나를 더한다. 이번 라운드 단어와 최종 화면에는 붙이지 않는다.
- 축 탭 개수 · 필터 개수 · 하위 카테고리 묶음은 위 목록 기준. 오른쪽 축 분포 · 승인 예정/거절 줄은 지금처럼 누적.
- 서버 · 저장 · 확정 요청 변경 없음(확정은 원래 이번 라운드 단어만 보냄).

## 대안
| 안 | 설명 | 판단 |
|---|---|---|
| A. 승인 누적 + 표시 (선택) | 위 동작 | 사용자 선택 |
| B. 승인 누적, 표시 없음 | 새 단어 구분 불가 | 사용자 거절 |
| C. 이번 라운드만(현재) | R1 승인 단어가 사라진 것처럼 보임 | 사용자 거절 |

## 수용 기준
- AC1: 세라젬 형태 세션 R3 화면 탭 "전체" = R3 단어 + R1 승인 단어(60 + 67 = 127). R1 거절 단어는 목록에 없다.
- AC2: R3 화면에서 R1 승인 단어 칩에 "R1" 표시, R3 단어 칩에는 라운드 표시 없음.
- AC3: R1 화면 = R1 단어 전부(87), 라운드 표시 없음. 최종 화면 = 전체 누적, 라운드 표시 없음.
- AC4: 축 분포 · 승인 예정/거절 줄 · 확정 · 거절 · 이동 · 직접 추가 동작 변경 없음.
- AC5: 기존 테스트 · 린트 · 빌드 통과.

## 제외 범위
- 서버 변경, 누적 보기 전환 버튼, 칩 모양 · 색 변경(표시 문구 하나만 추가).

## 위험
- R3 화면에서 이전 라운드 승인 단어를 거절하면 그 단어 상태가 바뀐다 — 예전 누적 화면에서도 가능했던 동작이라 그대로 둔다.
