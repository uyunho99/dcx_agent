## 범위 밖 발견 사항 — 후속 수정 필요

`backend/app/routers/keywords_v2.py`의 POST `/keywords/{sid}/events`는 `_all_keywords(data)`로 만든 맵으로 **저장된 모든 라운드**의 단어를 다시 조회한다. 이번 요구대로 미확정 잠금 R2를 `_all_keywords`에서 제외하면, 미확정 R2가 저장된 세션에서 보이는 R1 단어를 approve/reject/move/unreject할 때 R2 단어 ID 조회가 `KeyError`를 일으킨다.

메모리상의 R1 확정 + R2 미확정 데이터와 mock 저장소로 `api.event(... EventRequest(round=1, type='approve', kwId='r1'))`를 호출해 **`KeyError('r2')`, 쓰기 0회**를 재현했다. 디스크 세션은 사용/변경하지 않았다. 전체 suite에는 이 조합의 이벤트 회귀 테스트가 없다.

이번 소유 범위가 라우터의 **GET 응답 필터만** 허용하므로 POST 이벤트 경로는 수정하지 않았다. 코디네이터가 후속 작업으로 이벤트 패치가 필터에서 제외된 라운드의 기존 단어를 보존하도록 수정하고, 미확정 R2가 있는 상태에서 보이는 R1/R3 단어 이벤트 회귀 테스트를 추가해야 한다.
