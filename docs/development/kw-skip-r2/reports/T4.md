# T4 — 이벤트 저장 회귀 수정 및 기본 R1→R3→R4 테스트 정리

## 변경 파일

- `backend/app/routers/keywords_v2.py`: 이벤트 patch의 최상위 `keywords`와 각 `keywordRounds` 재구성에서 `all_kws.get(k['id'], k)` 사용. 필터 밖 미확정 R2 항목은 원본 그대로 보존하고 보이는 키워드는 기존 방식으로 갱신한다. 앱 변경은 이 두 조회뿐이다.
- `backend/tests/keywords/test_round_lock.py`: `test_events_with_pending_locked_round`에 approve/reject/move/unreject 4개 매개변수 추가. 확정 R1 + done/미확정 R2(`k_r2g1_0001`, pending)를 저장하고 HTTP 200, 두 저장 위치의 R1 변경, 디스크 session.json의 R2 전체 항목 불변 및 pending 유지 검증. approve/unreject는 rejected 상태에서 시작해 실제 상태 전환과 거절 사유 제거를 확인한다.
- `backend/tests/keywords/test_final_w1.py`: 일반 라운드 반복 및 후속 미확정 검사에서 잠긴 라운드 제외. 재시작 순서 검사는 R1 확정 전 R3의 409로 유지한다.
- `backend/tests/test_integration_stage0_2.py`: 비밀 키 목록에서 `keyword_locked_rounds` 제외, 기본 흐름 R1→R3→R4 반영. 테스트 임시 corpus의 R2 전용 표식을 R1 표식으로 바꿔 기존 200건 수집/전처리 계약 유지. 공유 corpus 생성기 변경 없음. 비밀 정보 검사에서 완료 라운드가 정확히 `[1, 3, 4]`인지 검증한다.
- `backend/tests/test_no_network.py`: 기존 R2 네트워크 테스트를 `keyword_locked_rounds=[]`로 실행하고 `[2]`의 R1 확정 변형도 추가. 두 변형 모두 외부 연결 0회와 autocomplete coverage connected 검증 유지.
- `docs/development/kw-skip-r2/logs/T4-red.txt`, `logs/T4-targeted-green.txt`, `logs/T4-green.txt`, `reports/T4.md`: 테스트 증거 및 보고.
