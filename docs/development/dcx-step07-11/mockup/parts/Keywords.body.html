[[ANN]]
1

치환라운드별 기법 분화. AS-IS는 코드 분기가 round==1과 else 둘뿐이라 R2·R3·R4가 모두 같은 확장 프롬프트를 탔다. R1 5W1H·JTBD / R2 SCAMPER / R3 수렴 / R4 역발상·부정공간으로 가른다. 화면의 라운드 명칭은 현행 ROUND_NAMES(R1 발산 · R2 발산 · R3 수렴 · R4 재발산)를 승계한다.

2

치환7개 flat 카테고리 → 3축. 현행 화면은 상황맥락 / 감정표현 / 문제상황 / 숨은니즈 / 타겟특화 / 시즌시간 / 공간장소 7개를 같은 층의 섹션으로 펼친다. 물리적 시간·공간과 심리적 감정·니즈가 한 층에 섞이고, 타겟특화는 "어떤 맥락인가"가 아니라 "누구인가"라 축이 다르다. 섹션 구조는 그대로 두되 물리 · 심리 · 행동 3축 + 하위 축으로 갈아끼운다 — 접기/펼치기, 칩 그리드, 드래그 이동, 축별 "＋" 입력 패널은 현행 그대로다.

3

치환HITL이 on/off에서 방향 지시로. AS-IS는 칩을 클릭해 승인·거절만 했고(rejected Set), 그 판단은 다음 라운드에 반영되지 않고 버려졌다. 검색량은 데이터 확보 가능성일 뿐 목적 관련성이 아니다. 거절에 사유 태그를 붙이고, 사전 방향 지시와 함께 R3 프롬프트로 누적 주입한다.

—

유지현행 키워드 보드 기능. 칩 클릭 승인/거절, 축 간 드래그 이동, 축별 수동 입력(쉼표 분리)과 중복 경고, 추천 단어(형용사·동사) 불러오기·전체 추가, 새 축 추가, 전체 접기/펼치기, 검색량 점수 배지(70↑ · 50↑ · 50미만)는 기존 코드의 동작을 그대로 옮긴다.

—

치환프롬프트 골격. 역할 부여("당신은 CX 전문가입니다")를 걷어내고 과업 프레이밍 + 사고 절차 4단계를 준다. 에어컨·보험 few-shot은 다른 제품에 편향을 유도하므로 형태 예시만 남긴다.

—

미결3V 중 Velocity. Volume은 검색량 자동 스코어링으로 코드화했고 Variety는 HITL 승인 게이트가 흡수했다. 트렌드 추세 검증(Velocity)은 현재 대응이 없다.
