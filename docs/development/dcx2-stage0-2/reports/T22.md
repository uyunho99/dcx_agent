## Actions and APIs
| Action | Call |
|---|---|
| Restore settings, keywords and drafts | GET `/session/{sid}` |
| Connection badges | GET `/integrations`; failed/missing endpoint yields unknown badges |
| Settings temporary save | PATCH `/session/{sid}` `{drafts:{crawl:{config}}}` |
| Settings save | PUT `/crawl/{sid}/config` with documented fields, then PATCH config draft to null |
| Start list | POST `/crawl/{sid}/list` without body |
| Added keywords | POST `/crawl/{sid}/list?mode=added-keywords` without body |
| Gate temporary save | PATCH `/session/{sid}` `{drafts:{crawl:{gate:{exclusions,snapshot_id}}}}` |
| Gate save | PUT `/crawl/{sid}/gate` `{exclusions}`, then PATCH gate draft to null |
| Start detail | POST `/crawl/{sid}/detail` `{snapshot_id}` from status |
| Resume | POST `/crawl/{sid}/resume` without body |
| Stop | POST `/crawl/{sid}/stop` without body |
| Refresh | GET `/crawl/{sid}/status` |
| Preprocessing | router navigation to `/pipeline/preprocess` |

Crawl mutations include `version` when available. Saves do not start workers. Starts require explicitly saved config/selection; temporary save alone does not enable them. No full `saveSession` call. Draft gate restoration requires a matching snapshot. New list creation clears local prior gate exclusions. Config sends `product_name_filter`, defaults false, and never adds bk to queries. All internal connection/snapshot elements are absent when INTERNAL_TOOLS is false. Unknown connection state does not prevent rendering or disable channels.

## Polling and concurrency
- Immediate initial status request; 3 seconds while running/stopping, 10 seconds otherwise, including idle/gate/done/interrupted.
- A serialized recursive timeout is used instead of shared usePolling's fixed setInterval: requests do not overlap; interval resets when lifecycle status changes. Cleanup cancels timers and suppresses unmounted responses.
- Status is refreshed after every action. A synchronous ref lock disables duplicate in-flight actions; starts are disabled while server status is running/stopping, during loading, or when status is unavailable.
- A request generation counter ignores polls issued before a mutation. Mutation failures require a fresh status before another start. Restoring a page never starts a worker.

## Windowing
- Up to 300 visible rows use the full semantic table. Above 300, `crawlWindow` calculates an exclusive visible range with five-row overscan and spacer heights.
- Row heights include each expanded detail row. ResizeObserver measures actual heights, including wrapping and zoom. Estimates are used only before measurement.
- Multiple expansions are preserved by keyword, and the sticky header remains inside the scroll container. A native button with aria-expanded provides Enter/Space expansion; row pointer clicks also expand. Checkbox events do not toggle expansion.
- Mini bars use `(listed - filtered) / sum(surviving counts)` with nonnegative finite normalization. Zero is dashed. Tooltips and screen-reader text include channel counts and ratios.
