# T19 — Person A 디자인 시스템 기반과 파이프라인 셸

## 결과

21개 typed React 컴포넌트, 목업 원문 토큰, 로컬 Pretendard, Tailwind 4 테마 연결, 224px 사이드바를 구현했다. 세션 복원 effect와 채팅 요청 callback은 유지했다. API 드로어는 아직 렌더링하지 않으며 `InternalToolsContext`에 `{drawerOpen, setDrawerOpen}`를 제공한다. `NEXT_PUBLIC_INTERNAL_TOOLS=false`이면 내부 API 버튼과 내부용 배지를 렌더링하지 않는다.

기본 빌드의 GREEN은 환경 제약 때문에 확인하지 못했다. 같은 코드의 Webpack 프로덕션 빌드는 성공했다. 아래에 기본 명령의 실패와 대체 검증을 구분해 기록한다.

## 목업 및 10절과의 차이

- 10절에 “7개”라는 문구가 있지만 목업과 기존 코드 모두 시작 포함 8개 탐색 항목이다. 기존 8개를 보존했다.
- 목업의 내비게이션/탭/그룹 라벨에는 sub색이 있으나, binding 규칙에 따라 실제 레이블은 ink로 바꾸고 sub는 캡션·힌트·메타에만 썼다.
- 목업의 현재 nav 항목에 있던 작은 그림자는 “그림자는 overlay만” 규칙에 따라 생략했다.
- 목업 전환 바는 제품 UI가 아니므로 포함하지 않았다. 셸은 전체 viewport 높이이며 목업의 전환 바 높이 38px을 빼지 않는다.
- 가짜 버전/연결 수/작업 진행률을 표시하지 않는다. activity는 빈 슬롯이며, 내부 API 버튼은 동사형 `외부 API 열기`와 내부용 neutral 배지를 쓴다. 실제 드로어와 데이터 연결은 후속 작업이다.
- 기본 224px/패딩 28×20, 로고 104px, 본문 32×32×64, 최대폭 1200, 12열/gutter 24를 적용했다. 1100px 이하에서는 목업처럼 사이드바를 72px로 줄이고 텍스트·footer를 감춘다.
- 좁은 확대 viewport에서는 채팅 패널을 overlay로 배치하고, 표 셀과 탭은 줄바꿈하며 통계는 쌓는다. 셸에는 1024px 강제 min-width를 두지 않았다. 이는 200% 확대에서 가로 overflow를 줄이기 위한 선택이다.
- 기존 페이지 스타일에 영향을 줄이지 않도록 DS 클래스는 `ds-`로 범위를 제한했다. 기존 glass 유틸리티는 기존 값 그대로 보존했다.

## 우려와 후속 확인

- 요구된 기본 `npm --prefix frontend run build`는 포트 바인딩을 허용하는 환경에서 다시 실행해야 한다. Webpack 성공을 기본 Turbopack GREEN으로 간주하지 않는다.
- 브라우저 실측/스크린샷, 키보드 상호작용, 200% 확대의 실제 QA는 수행하지 못했다. 기존 3단계 이후 본문은 변경하지 않았으므로 해당 본문의 확대 overflow까지 보장하지 않는다.
- 내부 도구와 activity API, 버전 UI는 후속 작업이다. 셸의 현재 이름은 기존 store의 `bk`를 사용한다.
- 기존 페이지 및 ChatPanel 내부 문구/스타일은 이 작업 소유가 아니므로 남아 있다. 이 보고서의 UI 규칙 적용 범위는 새로운 DS와 소유한 셸이다.
- 컴포넌트 단위 UI 테스트는 추가하지 않았다. 요청된 smoke test만 작성했고 컴파일/타입/정적 생성으로 통합을 확인했다.

## Git

지정된 파일만 스테이징하고 요청된 제목과 co-author trailer로 커밋을 시도한다. 결과는 아래에 기록한다.

`git add`는 exit 128:

```text
fatal: Unable to create '/Users/persona1/Desktop/dcx_agent/.git/worktrees/dcx_agent-dcx2-stage0-2/index.lock': Operation not permitted
```

이어서 요청된 제목/co-author로 `git commit --only <owned paths>`를 시도했지만, 앞서 add에 실패해 신규 파일이 index에 없어 exit 1로 끝났다:

```text
error: pathspec 'frontend/src/styles/tokens.css' did not match any file(s) known to git
error: pathspec 'frontend/src/components/ds' did not match any file(s) known to git
```

같은 pathspec 오류가 나머지 신규 파일에도 출력됐다.

결과: **uncommitted**. 워크트리의 실제 Git 메타데이터가 허용된 쓰기 경로 밖에 있어 index lock 생성이 거부됐다. 권한 상승을 시도하지 않았으며 다른 구현자의 파일을 스테이징하지 않았다.
