## Behavior and decisions

- `YoutubeAdapter.source` is `youtube`; availability checks whether `yt_dlp` imports, without an API key or network request. The dependency is loaded lazily.
- Search uses the keyword verbatim in `ytsearch{N}:{kw}`, with `extract_flat=True` in the `YoutubeDL` options (the Python `extract_info` method does not accept that option directly). Default N is 10, configurable through `videos_per_keyword`. Extraction uses `download=False` and `skip_download=True`.
- Search produces one bounded batch, `next_cursor=None`, and `total_hint` equal to the returned item count, not an estimated global YouTube result count. A supplied continuation cursor raises `ValueError`.
- Video title, ID, channel display label, duration, and view count live in `src_meta`. Both list and fetched document titles are empty. Metadata is explicitly selected rather than copying yt-dlp response dictionaries, URLs, or raw author identifiers.
- A nonempty video description becomes one document with `thread_key=""`, body equal to the description, and no comments. An empty description is omitted. This document does not count toward the comment limit.
- Each top-level comment becomes a document with `thread_key` equal to its comment ID and body equal to its text. Replies are grouped by `parent` into `Comment` records at depth 1; the top-level text is not duplicated as a reply. Roots are indexed before replies so response ordering does not affect grouping. Replies without a retained root are omitted rather than creating a false thread identity.
- Dates use UTC ISO calendar dates, falling back to video `upload_date` when necessary. Missing dates remain `None` on documents and empty strings on replies. Top-level raw author IDs are passed through the designated `author_raw` field for worker hashing; reply authors use the existing salted `author_hash` helper.
- Default `max_comments=30`; extractor arguments are `{'youtube': {'max_comments': ['30', 'all', '10', '5']}}`, matching the capture settings. The configurable first value caps roots plus replies in both extraction options and returned output. Zero disables comment extraction and emits only the description when present. Negative limits are rejected.
- `fetch(item, *, max_comments=N)` also supports the existing worker's per-run override without mutating shared adapter state. Each call owns a separate `YoutubeDL` context for concurrent leases.
- A yt-dlp `DownloadError` wrapping HTTP status 403 or 429 becomes `AdapterBlocked`, following `exc_info`, extractor `cause`, and Python exception chains. Other download failures propagate normally.
- Restricted video availability maps to `access="restricted"`; public or unspecified availability maps to `public`.
