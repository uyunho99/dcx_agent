## Normalization rules

- Lowercase scheme and host; retain path case.
- Drop fragments.
- Drop query parameters whose names begin with `utm_`, and `fbclid`, `gclid`, `art`, `query`, `where`, and `sm`. Matching is case-insensitive.
- Preserve other query parameters, including content identifiers `articleid`, `clubid`, and YouTube `v`; retain blank and repeated values. Sort remaining pairs by name and value and URL-encode them.
- Remove trailing slashes from the path.
- For `naver_cafe`, map `m.cafe.naver.com/ca-fe/<cafe>/<id>`, `m.cafe.naver.com/<cafe>/<id>`, and `cafe.naver.com/<cafe>/<id>` to `https://cafe.naver.com/<cafe>/<id>`.
- For `naver_blog`, map mobile and desktop blog paths to `https://blog.naver.com/<id>/<logNo>`.
- For `youtube`, map `youtu.be/<id>` and mobile watch URLs to `https://www.youtube.com/watch?v=<id>`. Preserve other non-tracking query parameters consistently with the general rule.

## Schema and hashes

- `Doc` has exactly the 17 fields in section 2.5. Comments have typed text, depth, date, and author_hash fields. Extra model fields are forbidden.
- Source, fetch_level, and access are validated against the specified values. Dates remain strings so `model_dump()` directly produces JSON-compatible data. All fields are required; empty strings and lists can represent absent content.
- Prefix map: `{"naver_cafe":"nc","naver_blog":"nb","youtube":"yt","ppomppu":"pp","clien":"cl","fixture":"fx"}`.
- Document IDs use the prefix, underscore, and `sha1(url_norm + thread_key).hexdigest()[:16]`, with UTF-8 encoding and an empty default thread key.
- Author hashes are `sha256(salt + source + raw_id).hexdigest()[:16]`: **16 lowercase hexadecimal characters**, matching section 2.5.
- Salt comes from `settings.author_salt_path`. Missing parent directories are created. New salt files contain `secrets.token_hex(32)`, are exclusively created using `os.open` with mode `0o600`, then explicitly chmodded to `0o600`.
- Salt is cached per resolved path with a thread lock. Existing salt content is reused. Raw author identifiers are neither returned nor logged.
- Hash tests monkeypatch the configured path to temporary files; the real data directory is never used.
