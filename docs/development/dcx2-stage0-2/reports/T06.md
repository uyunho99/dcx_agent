| Field | Type |
|---|---|
| `kw` | `str` |
| `axis` | `Literal["physical", "psychological", "behavioral"]` |
| `sub` | `str` |
| `why` | `str` |

`kw`, `axis`, and `sub` match the persisted Keyword field names. `why` is a generation rationale. Persistence metadata is assigned downstream. ## Decisions

- `RoundInputs` is a dataclass with exactly the brief's fields. The builder returns `LLMTask(task=f"kw_round_{n}", ...)`, using the unchanged LLMTask default token budget.
- Every task attaches the complete context content first as `project_context.md`. R2–R4 attach feedback second whenever it is not `None`, including an empty string. R1 never attaches feedback.
- Research questions are extracted from the context renderer's `- 리서치 질문:` line and quoted in each mission. If the line is absent, the mission refers to the question in the attached context.
- AXES supplies classification codes; templates supply Korean labels. Shared channel labels and BANNED are reused. YouTube and community channels permit colloquial expressions and abbreviations.
- R3 lists approved manual keywords as desired directions and includes available feedback verbatim beneath instructions to use its add/move records. This avoids depending on T07's future Markdown section syntax; feedback also remains attached in the required order.
- `PROMPT_VERSION` and `MIN_COUNT` match the brief exactly. R1 tones match the design verbatim. Invalid rounds raise `ValueError`; unknown R1 project types raise `KeyError` rather than silently selecting a tone.

## Concerns

- RoundInputs has no connection flag or prior-session existence flag. Callers must provide nonblank coverage text for connected coverage, even if no gaps exist. An empty past-zero list denotes no usable prior-session signal; it cannot distinguish missing history from history with no zero-result keywords.
- RoundInputs has no move-event field. Move information must be present in feedback; manual additions can also come from approved keywords. Full feedback is repeated in the R3 instruction body to retain these signals without guessing T07's section format.
- Direct research-question quotation depends on the context renderer's labeled line format. Context content remains attached even if that format changes.
- The existing `app/config.py:8` Pydantic class-based-config deprecation warning remains outside this task's scope.
