## Public types

Chose frozen dataclasses for result containers (nested lists and dictionaries remain mutable):

- `ListItem(url: str, title: str, snippet: str, date: str | None, src_meta: dict)`
- `ListPage(items: list[ListItem], next_cursor: str | None, total_hint: int | None)`
- `FetchedDoc(title: str, body: str, comments: list[Comment], date: str | None, src_meta: dict, access: Literal["public", "restricted"], author_raw: str | None, thread_key: str = "")`
- `AdapterBlocked(Exception)` documents the HTTP 403/429 signal for future real adapters.
- `ChannelAdapter(Protocol)` exposes `source: str`, synchronous `list_page(kw: str, cursor: str | None) -> ListPage`, `fetch(item: ListItem) -> list[FetchedDoc]`, and `is_available() -> bool` for availability reporting.

Reused `app.crawl.schema.Comment`: its text, depth, date, and author_hash fields fit the shared comment contract. Fixture documents have no comments.

## Registry and availability

`REGISTRY: dict[str, Callable[[], ChannelAdapter]]` contains only `fixture`. Its factory reads `settings.fixture_corpus_path` when called. `available_sources() -> list[str]` returns registry keys whose instantiated adapters report `is_available()`. Fixture availability requires both `settings.enable_fixture_channel` and a nonempty `settings.fixture_corpus_path`, evaluated at call time. Availability checks do not open the corpus. Future registered adapters must implement availability reporting.

## Fixture behavior

`FixtureAdapter(corpus_path, page_size=100)` reads UTF-8 CSV with optional BOM and a required `review` column. Loading is lazy, once per instance. A lock protects the module cache keyed by resolved path and nanosecond mtime; multiple instances share loaded reviews. Older cache entries for a changed path are evicted, while existing instances keep their original snapshot.

Rows use zero-based numbering excluding the header. Search uses the keyword verbatim as a substring and preserves row order. The opaque cursor encodes the next offset into matches; callers should pass it unchanged with the same keyword. Pages default to 100 items. URLs are `fixture://aircon/{row}`, titles are the first 30 characters, snippets use the same prefix, dates are `2025-01-01 + row days` in `YYYY-MM-DD`, and metadata is `{"row": n}`. Fetch returns one document with the complete body, no comments, public access, no raw author, and the default empty thread key.
