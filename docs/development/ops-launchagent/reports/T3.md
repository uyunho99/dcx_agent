- 변경 파일: `ops/macmini/README.md`, `docs/development/ops-launchagent/reports/T3.md`(이 보고서).
- 기존 LaunchDaemon 설명에 Codex 판정은 `--agent`로 설치하라는 안내를 추가했다.
- "운영 사용자 에이전트(권장)" 절에 D-342의 `Failed to synchronize managed preferences` 오류와 사용자 로그인 세션에서의 정상 동작, persona1 자동 로그인 유지·로그아웃 시 서비스 중단 조건을 기록했다.
- 데몬 해제·plist 삭제 → sudo 없는 `--agent` 설치와 직접 `y` 입력 → `dcxctl status`의 3단계, 드라이런, 에이전트 제거 후 sudo 데몬 재설치 절차를 추가했다.
- `ops/macmini/install.sh`를 읽어 명령과 동작을 대조했다. 운영 라벨·gui 도메인·등록 경로, sudo 거부, 확인 프롬프트, 데몬 잔존 시 1단계 명령 출력 및 변경 없는 종료, 드라이런의 가드 제외, 반대 방향 가드와 되돌리기 명령이 일치한다.
