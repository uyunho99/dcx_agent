# T4 — GPT 단독 라벨링 화면

## 구현
- `labelerMode?: 'cross' | 'gpt_only'`, nullable `mismatchRate` / `labelerAccuracy.jev` / 제출 결과 votes 및 선택적 nullable confidence를 공용 라벨 타입에 반영했다. progress의 기존 Record 타입은 Jev 키 생략을 허용한다. `lib/api/label.ts`는 공용 타입을 재사용하며 LabelVote도 내보낸다.
- `labelerMode.ts`에 `isGptOnly`, `formatRate`, 안내 제목·본문 상수 및 개요 표시용 `labelerView`를 추가했다. null/undefined 비율은 `—`, 숫자는 기존 소수점 한 자리 퍼센트로 표시한다.
- Overview는 기존 DS Banner(`role="status"`)로 전량 판정 카드 위에 안내를 표시한다. 시작 전·진행 중·완료에 유지하며 GPT 워커만 한 열로 표시하고 Jev 비용 문구를 숨긴다. 불일치율 두 곳 모두 공통 포맷을 사용한다. 코드값은 화면에 노출하지 않는다.
- KappaTable은 Jev 요약이 null이면 Jev 정확도를 `—`로 표시한다. Audit은 이 공통 컴포넌트를 사용하므로 별도 소스 수정 없이 null 안전하며 렌더링 테스트로 확인했다.
- QueueCard 비교값 함수를 queueView로 옮겨 null Jev 표의 모든 비교 칸이 `—`임을 테스트했다. GPT 이진 값 및 교차 방식 확률 표시를 보존했다.
- 라벨 confidence의 기존 화면 표시처는 없었다. 기존 응답에서 생략할 수 있는 필드이므로 선택적 nullable 타입으로 명시했다.
