## Changes

- GPT-only reconciliation consumes only the GPT vote journal using the existing `gpt` cursor identity. Done votes produce accepted `gpt_only` rows with GPT tags/reason/signal, rule-derived grade, NULL confidence, no mismatch/disagreement, and a null Jev vote. Missing or absent Jev caches are supported; only GPT failures enter the failure queue.
- Cross reconciliation replaces GPT-only rows when both votes are done, including when existing cursors are caught up. Human and model rows remain unchanged. Rule/question invalidation continues to recompute GPT-only rows.
- Sync/rebuild callers pass the persisted session mode through the T1 helper. Stage 4 completion and recovery read the selected version's session.json; GPT-only requires the latest GPT run to be done, while cross and started legacy sessions require both labelers.
- New final tables permit NULL confidence. Legacy NOT NULL tables are rebuilt transactionally, preserving rows and restoring captured indexes/triggers. Reopening is idempotent, and Label accepts nullable confidence and the GPT-only source.
