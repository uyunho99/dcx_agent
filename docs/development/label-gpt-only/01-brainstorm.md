# Jev 미연결 시 GPT 단독 라벨링 — 기획

## 문제
- Jev 키가 없다. 4단계 최종 라벨은 같은 글에 Jev 표와 GPT 표가 **둘 다** 있어야 만들어지고(`route.rebuild_final`), 4단계 완료도 Jev · GPT 실행이 모두 done이어야 한다(`stale._judges_complete`).
- 그래서 GPT(Codex)만 돌리면 1,000건을 다 판정해도 최종 라벨 0건, 4단계 미완료, 5단계 학습 불가.
- 운영 · QA는 `JEV_BACKEND=fake`다. 합치는 규칙상 등급은 Jev 값을 따르므로(`merge.merge`) 가짜 Jev로 돌리면 최종 라벨이 사실상 무작위가 된다. (2026-10-03 확인: 운영 세라젬 세션은 아직 판정 표 0건 — 오염된 라벨 없음.)

## 결정 (사용자, 2026-10-03) — D-340, D-341
- **A. GPT 단독 모드를 임시로 넣는다.** Jev를 실제로 쓸 수 없으면(키 없음 또는 fake) GPT 표 하나로 최종 라벨을 만든다.
- **confidence는 비운다(NULL).** Codex에게 확신도를 출력시키는 안은 택하지 않는다 — 보정되지 않은 값이고, GPT 질문 형식이 바뀌면 이미 받은 GPT 판정 캐시를 전부 다시 받아야 한다.

## 대안
| 안 | 설명 | 판단 |
|---|---|---|
| A. GPT 단독 모드 (선택) | Jev 없으면 GPT 판정을 그대로 채택, 출처 `gpt_only` 표시 | 사용자 선택 |
| B. Jev 키까지 대기 | 4단계 정지 | 사용자 거절 |
| C. 가짜 Jev로 진행 | 등급이 무작위 | 불가 |
| confidence: Codex 자기 보고 | GPT 출력에 확신도 추가 | 보정 안 됨 · 캐시 무효화 → 택하지 않음 |

## 동작 (예시)
- Jev 미연결 세션에서 "판정 시작" → GPT 판정만 돈다. Jev 카드는 "Jev 미연결 · GPT 단독 판정"으로 바뀐다.
- GPT가 글 1,000건 중 990건 판정 성공, 10건 실패 → 최종 라벨 990건(출처 GPT 단독, 채택), 검수 큐 10건(판정 실패). GPT 실행이 끝나면 4단계 완료 → 5단계 학습에 990건 사용.
- 등급 불일치 검수는 생기지 않는다. 오류는 기존 무작위 감사(D-145)로만 잰다. 불일치율 · κ는 "—".
- 나중에 Jev 키가 생겨 Jev 판정을 돌리면, 두 표가 다 있는 글은 기존 교차 규칙으로 다시 합쳐 GPT 단독 라벨을 대체한다. 사람이 검수한 라벨은 그대로.

## 수용 기준
- AC1: Jev 미연결(키 없음 또는 fake)이면 라벨링 시작 시 Jev 실행을 만들지 않는다. Jev 실행을 직접 요청하면 409와 한국어 안내.
- AC2: GPT 판정이 done인 글마다 최종 라벨 1행: 출처 `gpt_only`, 채택, 등급 = GPT 태그로 규칙 계산, confidence NULL, 불일치 없음.
- AC3: GPT 단독 모드에서는 GPT 실행만 done이면 4단계가 완료된다.
- AC4: 5단계 학습 대상에 GPT 단독 채택 라벨이 포함되고, 소프트 라벨은 GPT 0/1만 쓴다. 내보내기에서 confidence는 null.
- AC5: 기존 labels.sqlite(confidence NOT NULL)가 행 · 트리거를 잃지 않고 NULL 허용으로 바뀐다.
- AC6: 교차 모드(Jev 사용 가능)가 되면 두 표가 있는 글의 GPT 단독 행이 교차 합의 행으로 바뀌고, 사람 검수 행은 유지된다. 기존 교차 모드 동작 · 테스트는 그대로.
- AC7: 라벨링 화면에 "Jev 미연결 · GPT 단독 판정" 안내, Jev 시작 · 재개 버튼 없음, κ · 불일치율 · confidence는 "—".
- AC8: 백엔드 pytest · 프런트 lint · build · test 통과.

## 제외 범위
- Jev 실제 연동 확인, GPT 질문 · 출력 형식 변경, confidence 대체 지표.
- 이미 가짜 Jev로 만든 최종 라벨의 자동 정리(운영에는 없음).

## 위험
- 단독 모드는 교차 검증이 없어 GPT의 체계적 오류가 그대로 학습된다 → 화면에 단독 표시, 감사로 측정, Jev 연결 시 재합의.
- confidence NULL을 가정하지 않은 코드가 남아 있으면 화면 · 내보내기 오류 → 전수 검색 + 테스트.
- 테스트가 fake Jev 교차 합의에 기대고 있음 → 테스트 전용 명시 설정으로 교차 모드를 켠다.
