# DCX 2.0 6~8단계 백로그

## B-118 클러스터링과 경험 차원 추출 분리 (사용자, 2026-10-03)
- 현재 6단계 순서: 적재 → L1 클러스터 → L2 페르소나 → L3 컨텍스트 → 품질 → **경험 차원(LLM)** → 이름 초안(LLM). 경험 차원이 끝나야 이름 초안 · 확정 화면을 쓸 수 있어 클러스터링 결과를 바로 볼 수 없다.
- 경험 차원이 이름 초안 앞에 있는 이유는 컨텍스트 이름 초안이 `dominant_constraint`를 참고하기 때문뿐. 7단계 combo_rarity · 8단계 인사이트는 뒷단계 용도.
- 바꿀 방향: 6단계는 클러스터링 + 이름 초안(키워드 · 대표 원문 기반)까지만 하고 바로 확인 · 확정. 경험 차원은 분리해 백그라운드 또는 7단계 진입 시 실행, 끝나면 컨텍스트 주요 제약 등을 화면에 추가.
- 함께 검토: 표본 25건을 먼저 보여 주고 나머지(예: 75건)를 백그라운드에서 채우며 통계를 순차 갱신.

## B-119 경험 차원을 딥러닝 기반 기법으로 계산 (사용자, 2026-10-03)
- 원래(1.0)는 경험 차원을 LLM 호출이 아닌 다른 딥러닝 기반 기법으로 계산했다. 현재 2.0은 컨텍스트별 표본을 LLM(OpenAI · Codex)으로 추출해 느리고 표본에 한정된다.
- 1.0 방식을 다시 도입하거나 대체 기법을 검토(전량 계산 가능 여부, 비용, 품질 비교). 1.0 방식 자료는 사용자에게 확인.
