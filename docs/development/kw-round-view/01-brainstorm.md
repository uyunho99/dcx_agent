# 키워드 화면 — 고른 라운드의 단어만 보기 · 기획

기준: origin/main `9b8edeb`

## 문제
키워드 화면의 "검토할 라운드"를 바꾸면 제목만 바뀌고 키워드 목록은 바뀌지 않는다. 목록은 언제나 모든 라운드를 합친 누적 목록이다(`frontend/src/app/pipeline/keywords/page.tsx:92` `reviewKeywords`).
- 세라젬(QA 복사본): R1 선택 → 제목 "R1 … 87개", 탭 "전체 147". R3 선택 → 제목 "R3 … 60개", 탭 "전체 147". 같은 칩이 보여 사용자는 "R1과 R3가 똑같다"고 판단했다.
- 실제 R3 60개는 R1 승인 67개와 핵심어가 겹치는 단어가 0개다.

## 결정 (사용자, 2026-10-02)
- 고른 라운드에서 나온 단어만 목록에 보인다. R3를 고르면 R3 60개만 보인다.

## 동작
- 목록 · 축 탭 개수 · 필터 개수(판단 필요 · 미연결 등) · 하위 카테고리 묶음 = 선택한 라운드의 키워드만(`round === 선택 라운드`).
  - 그 라운드 화면에서 직접 추가한 키워드도 그 라운드 번호로 저장되므로 함께 보인다.
- 최종 화면(R4 확정 후 "최종 키워드를 검토합니다")은 지금처럼 전체 누적 목록.
- 오른쪽 "축 분포" 카드와 "승인 예정 N · 거절 M" 줄은 지금처럼 누적(다음 라운드가 무엇을 채울지 보는 용도).
- 서버 · 저장 · 중복 판정 · 승인 목록 · 확정 요청은 변경 없음. 확정은 원래 그 라운드 단어만 보낸다.

## 대안
| 안 | 설명 | 판단 |
|---|---|---|
| A. 선택 라운드만 (선택) | 위 동작 | 사용자 요청 |
| B. 누적 보기 전환 버튼 추가 | 기본은 선택 라운드, 버튼으로 누적 | 버튼 추가는 이번 제외(필요하면 다음 작업). 최종 화면이 누적 보기 역할 |

## 수용 기준
- AC1: 세라젬 형태 세션에서 R1 선택 시 목록 · 탭 "전체" 수가 R1 키워드 수(87), R3 선택 시 R3 키워드 수(60).
- AC2: R4 확정 후 최종 화면은 전체 누적 목록.
- AC3: 축 분포 카드 · 승인 예정/거절 줄은 누적 값 그대로.
- AC4: 거절 · 이동 · 직접 추가 · 확정 · 임시 저장 동작과 요청 값 변경 없음.
- AC5: 기존 프런트 테스트 · 린트 · 빌드, 백엔드 테스트 통과.

## 제외 범위
- 서버 변경, 누적 보기 전환 버튼, 단계 표시 · 문구 변경.

## 위험
- 이전 라운드 단어를 거절하려면 그 라운드를 골라야 한다(확정된 라운드는 원래 편집 불가라 영향 작음).
