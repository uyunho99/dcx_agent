## 1. 문제와 목표

7단계 Evidence Package 하나만 입력으로, 6단계에서 사람이 확정한 Persona마다 근거 인용이 달린 카드(8-A CCM · 8-B 수렴 · 8-C 속성 · 8-D 처방)를 만들고, 세션 전체 Opportunity Map에서 기회 지점을 고른 뒤, 인사이트(8-E)와 경험 디자인 컨셉(8-F)을 만들어 채팅으로 다듬고 확정한다. 모든 서술은 근거 번호로 원문까지 따라갈 수 있어야 하고, 근거가 약한 칸은 등급(관측 · 추론 · 추측)으로 드러난다.

## 2. 범위 (02-design 12절 묶음 ③)

- 2.5 8단계 저장(`persona/`) · 5.1~5.10 · 6절(8단계 · 인사이트 사이드바 · 8부터 다시) · 7절 `persona` · `insight` 워커 · 8절 persona · insight API · 10절 화면 8(전체 맵 · Persona 카드 · 인사이트) · 11절 8단계 테스트
- 가짜 Evidence Package 픽스처(02-design 2.4 스키마, 합성 세션 기반)로 7단계 없이 시험(D-248).

## 6. 위험

- 인식론 등급 판정이 인용 확인(`verified`)에 달려 있음 — ② 실제 출력의 미확인 비율이 높으면 대부분 🟡/🔴. 실세션 확인(D-247)에서 봄.
- 채팅 수정이 스키마를 깨는 응답을 내면 판이 안 바뀜 — 설계대로 실패 문구 + 현재 판 유지.
- 처방 제약 검사는 LLM 판정 — 차단 문구가 보이는지 QA에서 확인.
