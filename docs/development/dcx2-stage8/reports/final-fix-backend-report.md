## Decisions and concerns

- A fresh run means a complete rebuild, even if a request also carries a partial persona selection; ordinary retry/resume keeps its existing selection behavior.
- A reset intentionally removes old insights. The operation lock and generation guard ensure a chat still in flight when reset starts fails rather than claiming a successful edit against the discarded generation.
- Preparation model/dimension incompatibility follows the existing Known resolver policy: fail clearly rather than use an incompatible global embedding configuration.
- Existing fixtures were updated to represent writable sessions, compatible preparation providers, real evidence for completion checks, and the revised API/outdated-concept contracts.
- D-316 remains deferred: no stage-eight version-selection UI changes and no insight prompt-size reduction.
- Validation uses local fake providers; no live LLM/embedding credentials or external services were required.
- No blocking backend concerns remain. The two deselected tests follow the existing suite configuration; D-316 deferrals remain unchanged.
