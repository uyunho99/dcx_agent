# 결정 기록 — 키워드 거절 팝오버 가림 · 표시 띄어쓰기

번호는 `dcx2-stage0-task-mode/decision-log.md`(main, 마지막 D-330)에 이어 붙인다. main 병합 시 그 파일로 옮긴다.

### D-331 키워드 띄어쓰기는 화면 표시만 · D-325(두 단어 이하) 유지 · 확정 (2026-10-02)
- 사용자 선택: "규칙 그대로, 표시만 띄어쓰기". 대안이던 "세 단어까지 허용"(D-325 완화)과 "두 단어 강제"는 택하지 않았다.
- 서버가 응답에만 `display`를 붙인다(Kiwi 띄어쓰기). 저장 `kw`, 수집 검색어, 중복 판정은 그대로다.
- 한 글자 조각 규칙: 전·후·중·약·앱·길·날과 관형사·부사 등은 따로 두고, 선·암·초·입·노·회 같은 접두 성격 글자는 뒤 단어에, 나머지는 앞 단어에 붙인다(실데이터 476개로 조정).
- 기획안과의 차이: 기획안에는 표시 형태 규정이 없다. 분석기 오분할(예: "제 증명 창구")은 표시에만 남으며 원문은 마우스를 올리면 보인다.

### D-332 키워드 거절 팝오버가 열리면 좌측 사이드바 자동 접기 · 접기 버튼 추가 · 확정 (2026-10-02)
- 사용자 선택: "접기 버튼 + 팝오버 열 때 자동 접기".
- 팝오버를 닫으면 열기 전 상태로 복귀한다. 사용자가 접어 둔 상태는 브라우저에 저장된다. 팝오버는 본문 경계를 넘으면 반대 방향으로 펼친다.
