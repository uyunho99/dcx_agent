# T3 — 사이드바 접기 및 팝오버 자동 접기

## 구현

- `createSidebarAuto(onChange)`는 요청 수가 0↔1 경계를 지날 때만 알린다. 각 해제 함수는 한 번만 적용되며, 동시 요청은 모두 해제되어야 자동 접힘을 해제한다.
- `SidebarAutoProvider`와 `useSidebarAuto()`를 추가했다. Provider 밖에서는 요청과 해제가 아무 작업도 하지 않는다.
- `PipelineShell`은 사용자 선택과 자동 접힘을 별도 상태로 관리하고 `sidebarCollapsed(user, auto) = user || auto`로 합성한다. 사용자 선택만 `dcx.sidebar.collapsed`에 저장하며 읽기와 쓰기를 모두 try/catch로 보호한다. 기본값은 펼침이다.
- 상단 로고 옆에 DS Button/Icon 및 PanelLeftClose/PanelLeftOpen을 사용하는 최소 36×36 토글을 추가했다. 상태별 한국어 레이블, `aria-expanded`, `aria-controls="pipeline-side"`, aside ID와 shell의 `data-side`를 연결했다.
- 기존 1100px 이하 사이드바 규칙을 명시적 접힘 상태에도 적용했다. 토글은 표시되며, 소형 화면 전용 채팅 및 그리드 규칙은 유지했다.
- `KeywordChip`은 mode가 non-null이면 요청하고 effect cleanup에서 해제한다. 취소·확인 성공·Esc·닫기에서 mode가 null이 되거나 칩이 언마운트되면 해제된다. T2의 `keywordLabel`/`keywordTitle` 변경은 보존했다.
