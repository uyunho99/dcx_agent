## 중복 테두리 원인과 수정

소스 구조 확인: KeywordChip은 Popover 하나를 렌더링하고 그 안에 RejectPopover의 일반 form/fieldset을 넣는다. RejectPopover에는 `.ds-pop`이나 `.ds-card`가 없다. ds.css의 두 `.ds-pop` 규칙은 동일 요소에 적용되는 CSS 선언이며 두 패널을 생성하지 않는다.

코드에서 확인한 두 번째 프레임 생성 경로는 **패널 자체의 focus-visible outline**이다. Popover는 열릴 때 `tabIndex={-1}`인 패널에 `.focus()`를 호출한다. `globals.css`의 전역 `:focus-visible { outline:2px solid var(--action); outline-offset:2px; }`가 적용되면 `.ds-pop`의 1px border 바깥에 떨어진 프레임이 생긴다. RejectPopover의 입력 포커스 rAF와 부모의 패널 포커스 effect도 있어 패널이 포커스를 받는 경로가 존재한다.

`.ds-pop:focus-visible`에 `outline:none; border-color:var(--action)`을 적용했다. 패널 포커스는 기존 단일 테두리 색으로 표시하며 버튼·입력의 포커스 외곽선은 유지한다.

브라우저 확인 한계: Chrome은 사용 가능한 브라우저가 아니었고 Safari Computer Use 접근은 승인되지 않아 라이브 DOM 개수·중첩 검사 및 스크린샷 재현은 수행하지 못했다. 위 원인은 소스 분석으로 확인한 렌더링 경로이며, 원본 스크린샷과의 시각적 일치 및 사이드바 접힘 이후의 실제 화면 QA는 미검증이다.

## F1 fix

Thread: `01a0fc41-be45-75a2-89b0-436c7ab879ab`. No commit; backend and other workers' files untouched.

### Root cause

- `KeywordChip` requests sidebar collapse in a passive effect after opening. The old Popover scheduled only one initial rAF plus a window resize listener. A sidebar layout change after that measurement does not resize the window, so the chosen alignment stays stale. ResizeObserver alone also cannot detect position-only movement.
- The missing attribute is a separate lifecycle defect: JSX never supplied `data-align`; only the deferred callback created it, and effect cleanup explicitly removed it. Thus initial render and cleanup/replay expose a panel without an alignment. Regression tests reproduce both absent-attribute paths against the old implementation. A normal sidebar rerender does **not** itself rerun an effect depending only on `[open, contained]`; it would be incorrect to claim that rerender necessarily invokes cleanup. The precise lifecycle sequence behind the reported 5/8 browser samples has not been instrumented/reproduced in this run; a persistent absence after a completed callback cannot be explained by the layout shift alone.

### Change

- `frontend/src/components/ds/Popover.tsx`: render `data-align="end"` immediately; delegate measurement lifecycle to the helper. Preserve the `open`/`contained` exclusion and existing focus/Escape effects.
- `frontend/src/components/ds/popoverMeasure.ts` (new): locate nearest overflow ancestor; observe boundary, trigger, and panel sizes; retain initial rAF and window resize handling. While open, compare trigger/boundary geometry each animation frame to catch position-only shifts (including scroll); unchanged frames do not write alignment or measure trial panel positions. Observer callbacks measure synchronously before paint, and end/start trials plus final choice occur in one callback. Cleanup cancels rAF, disconnects the observer, removes the listener, and guards late callbacks without deleting alignment.
- `frontend/src/components/ds/popoverMeasure.test.ts` (new): eight tests covering initial markup (including contained), fake ResizeObserver registration/callback correction, position-only movement and reversal, cleanup/late callbacks, window resize, unchanged-frame behavior, nearest boundary selection, border offsets, and viewport fallback.
- `popoverAlign.ts` and its seven existing tests are unchanged.
