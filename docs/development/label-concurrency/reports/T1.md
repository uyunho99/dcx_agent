# T1 — GPT 묶음 동시 처리

- 기준: 02-design.md, 03-plan.md, D-343. 커밋하지 않음.
- GPT 임대량을 batch_size × max(1, concurrency)로 확대하고 임대 순서대로 분할한다. ThreadPoolExecutor와 as_completed로 완료된 묶음부터 워커 메인 스레드에서 put/fail한다. Jev 분기는 그대로 유지한다.
- 사용량 한도 묶음은 기록하지 않고 임대를 해제한다. 일반 LabelerPaused는 gpt_backend_failed, 누락 ID는 invalid_or_missing_vote로 기존 fail 재시도 규칙을 적용한다(3회째 bad). 다른 묶음 결과를 저장한 뒤 일시정지하며, 한도 메시지를 우선한다. 예상하지 못한 예외는 다른 묶음 저장 이후 다시 던진다.
- sync의 mode 인자, 그룹 사이 heartbeat 및 기존 임대 갱신을 유지한다. gpt.py는 단일 작업 run_many의 concurrency=1만 변경했다.
- 새 테스트 13개: 4-way Barrier(5초), concurrency=1 및 0의 직렬 처리, 각 문서 정확히 한 번 put, 메인 스레드 put/fail, 한도/일반 일시정지, 혼합 사유 우선순위, 누락, 예외 전파, 기존 실패 횟수 0/2에서 재시도 상태와 임대 해제.
